# Security policy

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/code-mortis/code-mortis/security/advisories/new). If the form is unavailable, open an issue requesting a private reporting channel and keep vulnerability details out of the issue.

Include the affected version, commit, or image tag, the impact, and the shortest reproduction you can share safely. Remove tokens, GitHub App private keys, provider credentials, and private repository content. Share sanitized excerpts from logs and scan reports in place of full exports or `.env` files.
