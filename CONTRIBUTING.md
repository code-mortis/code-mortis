# Contributing to Code Mortis

Follow the [local development setup](README.md#develop-locally) to start the stack. Use the [local checks](AGENTS.md#local-checks) for the parts of the project you change.

- Open an issue for a reproducible bug or a feature proposal. Discuss broad changes before implementation.
- Keep pull requests focused. Explain the change, link a related issue when applicable, and report the checks you ran.
- Add a focused regression check for behavior changes. Use synthetic fixtures and omit credentials, private repository content, and real scan reports from issues and pull requests.
- Report vulnerabilities privately using the [security policy](SECURITY.md).
